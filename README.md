# WSM Garage — сайт мастерской порошковой покраски

Демо-лендинг для мастерской WSM Garage (Сысерть): порошковая покраска и реставрация дисков, суппортов и металлических деталей.

Сайт: https://amave423.github.io/wsmgarage/

## Что есть

- калькулятор стоимости в прайсе (радиус, количество, покраска, доп. работы);
- подбор цвета RAL на интерактивной 3D-модели диска (глянец, мат, металлик);
- выдвижная форма заявки с фото изделия (в демо заявка никуда не отправляется);
- галерея работ, отзывы, FAQ, карта.

## Запуск

```bash
npm install
npm run dev
```

Все данные (цены, контакты, отзывы, фото) — в `lib/data.ts`, заглушки помечены `TODO`.

## Стек

Next.js (App Router, статический экспорт) + Tailwind CSS + three.js. Деплой на GitHub Pages через GitHub Actions при каждом пуше в `main`.
